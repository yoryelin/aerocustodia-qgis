# AeroCustodia - Official QGIS Plugin

**AeroCustodia** is a precision territorial and satellite intelligence plugin for QGIS designed for agronomists, rural appraisers, and agricultural producers.

It allows you to download calibrated, cloud-free satellite imagery in one click, analyze crop vigor (NDVI), assess topography (SRTM DEM), verify European deforestation compliance (EUDR), and export **interactive GeoPDF maps with real-time GPS tracking** for offline field scouting in **FO Maps** and **Avenza Maps**.

---

## 🌟 Key Features

1. **Vegetation Indices (Sentinel-2 Calibrated NDVI):**
   - Cloud-free median mosaics with BOA reflectance calibration.
   - Temporal window selector (last 15 days or custom date range).
   - Instant 5-class agronomic vigor symbology.

2. **Topography & Relief (SRTM 30m DEM):**
   - High-resolution digital elevation models.
   - Slope analysis, water runoff patterns, and flood-prone lowlands detection.

3. **EUDR Deforestation Compliance:**
   - Forest cover verification aligned with EU Regulation 2023/1115 (December 2020 cut-off baseline).

4. **1-Click GeoPDF Export (Offline Mobile GPS Scouting):**
   - Directly converts your QGIS canvas into a georeferenced GeoPDF.
   - 100% compatible with **FO Maps** and **Avenza Maps** on Android and iOS.
   - Walk the field watching your live blue GPS dot over the NDVI layer without cellular connection.

---

## 🚀 Installation

1. In QGIS, navigate to `Plugins` -> `Manage and Install Plugins`.
2. Search for **AeroCustodia** and click **Install Plugin**.
3. Access the plugin from the QGIS toolbar or the `Raster` menu.
